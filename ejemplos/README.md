# Ejemplos de código de los capítulos

Cada capítulo incluirá ejemplos ejecutables relacionados con el producto **Grocery Delivery**:

- JavaScript: arrays de productos, filtros, cálculos, funciones puras.
- TypeScript: Money, Category, Product, Cart y tipos de resultado.
- React: componentes y estados de búsqueda, producto, cantidad y carrito.
- React Native: cabecera, banner, categorías, cards, navegación y checkout.
- Arquitectura: puertos, casos de uso, repositorios, adapters y tests.
- Avanzado: sync offline, ubicación, tracking, permisos y alertas.

Cada ejemplo tendrá README, entorno/requisitos, comandos de ejecución, pruebas y vínculo con el capítulo. No se añadirán ejemplos sin implementación funcional ni verificación.
