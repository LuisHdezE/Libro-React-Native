# Ejemplos por capítulo

Cada capítulo tendrá una carpeta `capitulo-XX` con ejemplos independientes, código TypeScript y un README de ejecución. Solo se publicarán ejemplos que correspondan al manuscrito ya redactado, revisado y probado.

Convenciones: TypeScript estricto, nombres consistentes, sin secretos ni credenciales, y decisiones arquitectónicas justificadas.
